一句话结论：同样 3GW 电力下，英伟达 GB200 方案约 143 万张卡、990 亿美元（等效算力更高）；昇腾 Atlas 950 方案约 284 万张卡、708 亿美元（便宜约 30%，但等效算力只有英伟达的一半）。真正的瓶颈：英伟达被禁运，昇腾产能不足（年产能仅需求的 1/4-1/10）。

一、核算口径与方法论（先讲清楚怎么算）

本次核算遵循固定链路，每个环节单独列参数、列依据，避免"拍脑袋"：

3GW 站点总电力 → PUE 折算 → IT 可用电力 → 负载率 修正 → 机柜/集群数 → 卡数 → 单价 → GPU 系统成本 + 基建成本 → 总投资
  1. 口径定义：3GW 指站点总供电容量（含 IT 负载 + 制冷 + 配电损耗 + 冗余），是行业立项口径。
  2. 理论值 vs 实际可落地：理论 = IT 电力满载连续运行；实际 = 考虑负载率（85%）、N+1 冗余、峰值余量后的可持续负载。
  3. 算力口径：英伟达官方规格为"稀疏（sparse）"值，稠密为稀疏一半；昇腾为稠密口径。对比时已做说明，避免数字打架。
  4. 价格口径：GPU 系统 = 整柜/整集群采购价（含互联）；基建 = 土建+供配电+制冷+网络配套，按行业每 MW 造价。
  5. 等效算力锚点：采用 DeepSeek 创始人梁文锋实测口径——"16000 张华为 950 ≈ 4000 张英伟达 B 系列"（4:1），这是目前最权威的第三方实测数据。[S7]

三、英伟达方案核算（GB200 NVL72 为主方案）

3.1 电力折算

IT 电力 = 站点总电力 ÷ PUE = 3,000MW ÷ 1.2 = 2,500MW

PUE 取值依据：现代液冷超大规模数据中心设计 PUE 1.15-1.25（GB200 全液冷是标配）；中国新建智算中心设计值普遍 ≤1.25。取 1.2 为中性值。敏感性见第六节。

3.2 卡数与算力（理论值 = 满载）

机柜数 = 2,500,000kW ÷ 125kW/柜 ≈ 20,000 柜
GPU 数 = 20,000 柜 × 72 卡 = 144 万张 B200
总算力 = 20,000 柜 × 1.44 EFLOPS(FP4) = 28.8 EFLOPS FP4

整柜功耗取 120-132kW 区间中值 125kW [S2]；单柜 FP4 1,440 PFLOPS 为 NVIDIA 官方规格（稀疏）[S1]。

四、昇腾方案核算（Atlas 950 SuperPoD 超节点）

4.1 集群参数

单集群 = 1,024 卡（950PR/DT）| FP4 2 EFLOPS | 功耗 ≈ 900kW（整系统含卡+CPU+互联+液冷）| 价格 ≈ 1,500 万美元[S13]

集群功耗估算：950PR 600W × 1024 卡 = 614kW 纯卡，加鲲鹏 CPU、灵衢交换、电源与液冷损耗 ≈ 850-950kW，取 900kW。价格含机柜+灵衢互联+液冷（雪球拆解口径 1,500 万美元/1024 卡集群）。

4.2 卡数与算力（理论）

集群数 = 2,500,000kW ÷ 900kW ≈ 2,778 集群
卡数 = 2,778 × 1,024 = 284 万张昇腾 950
总算力 = 2,778 × 2 EFLOPS = 5.6 EFLOPS FP4（稠密口径）

七、现实约束（为什么不能只看纸面）

7.1 禁运：英伟达方案在中国不成立

  • 2023.10 起 B200/H100 对华禁售；2025.4 起 H20 也需出口许可。
  • 合规可购的 H20：FP16 仅 150 TFLOPS（B200 的 ~1/130），400W/卡。3GW 若全用 H20 需 ~470 万张、且等效算力仅 GB200 方案的 ~2%。[S3]
  • 结论：中国 3GW 集群实际只有昇腾（或存量英伟达）路线。本文英伟达核算用于对照"花同样的电力/钱能买多少算力"。

7.2 产能：昇腾最大的硬约束

  • 梁文锋实测：华为给 DeepSeek 的产能 ~1.6 万张/年，互联网大厂十几万张/年。[S7]
  • 路透社/新浪口径：昇腾 950PR 2026 年计划销售 ~75 万片。[S11]
  • 3GW 需求 242-284 万张 → 按当前产能需排产 3-10 年。这也是现实中没有"纯昇腾 3GW"立项的原因。

7.4 参考锚点：全球 3GW 级项目

  • OpenAI Stargate：规划 5GW+、四年 5,000 亿美元 → 3GW 约 3,000 亿美元口径（含运营），与本测算同量级。[S18]
  • Meta/微软单园区：500MW-1GW，投资 50-150 亿美元 → 3GW ≈ 300-900 亿美元，与本文 610-1,020 亿$ 区间吻合。

八、现实路线：混合方案（国内头部厂商实际做法）

既然纯英伟达不可行、纯昇腾产能不足，现实立项通常是：

场景推荐算力理由
大模型训练（前沿）英伟达存量卡 + 灰市补充CUDA 生态 + 训练效率
训练（国产）昇腾 950DT 超节点万卡集群已跑通 DeepSeek V4
推理/推荐（规模化）昇腾 950PR128GB 显存、单卡 7 万 RMB 性价比
边缘/小模型昇腾 910B/C存量产能、成本低
务实口径：3GW 立项中 30-40% 用昇腾（推理+国产训练）、60-70% 依赖存量英伟达/灰市或分期建设，实际投资落在 700-900 亿美元区间，且需 3-5 年分期落地。

九、最终结论

🟢 英伟达 GB200 方案

122-144 万张 B200

860-1,020 亿美元

等效算力基准（2×昇腾）

❌ 禁运，中国不可行

🟡 昇腾 Atlas 950 方案

242-284 万张昇腾 950

610-740 亿美元

等效算力仅英伟达 ~50%

⚠️ 产能需 3-10 年排产

  1. 电力不是瓶颈，芯片才是：3GW 电力配套（变电站/占地）约 240-360 亿美元可解决；卡才是卡点。
  2. 同电力下英伟达等效算力是昇腾的 2 倍：昇腾靠"更省电的单卡 + 更低的单价"缩小差距，但单卡算力 10 倍差距无法完全弥补。
  3. 昇腾单位等效算力成本高 ~45%：买同样算力昇腾更贵——这是禁运背景下的"自主可控溢价"。
  4. 3GW 昇腾集群现实不可一日建成：年产能 75 万张 vs 需求 284 万张，实际是 3-5 年分期 + 混合架构。
  5. 投资量级：无论哪条路线，3GW ≈ 600-1,000 亿美元（4,300-7,200 亿人民币），属国家级/超级云厂商体量。
