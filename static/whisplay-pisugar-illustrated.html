Whisplay HAT + PiSugar 图解
这块 65×30mm 的小屏，到底能干什么

硬件事实核对：PiSugar 官方产品页 / 官方文档站 / 驱动仓库 PiSugar/whisplay · 2026-09-13

一句话：Whisplay 是给树莓派装上"五官"（屏 + 麦克风 + 喇叭 + 灯 + 按键）的扩展板；PiSugar 不是一根电源线，它是把一台树莓派从"插着电的板子"变成"能揣兜里带走的小机器"的那套东西。

关键关系：两者同厂——都是广州 PiSugar Kitchen 做的。Whisplay 负责"输出与交互"，PiSugar 负责"活多久、怎么开机、怎么知道自己有电"，合起来才是一个完整的手持设备。

一、先把结构看懂：这是一块三明治

你手上那块东西不是"一块板"，是三层堆叠：上面一层负责表达，中间一层负责算，下面一层负责活。图里每一格的文字都是官方规格，可以直接对号入座。

采购级别的细节提醒：官方商店的产品文案里写过 "1.96-inch"，但技术规格表和第三方零售页写的是 1.69″ / 240×280。以 1.69″ 为准——你要给屏幕写 UI 或者做贴合外壳时，这个数字错了整块壳就废了。

还有个容易被忽略的第五件：软件层它替你想好了

很多人以为买 HAT 等于买硬件，其实 Whisplay 的价值有一半在驱动仓库 PiSugar/whisplay 里——它不只是点亮屏幕的脚本，还带一个 daemon 服务，把"屏幕、背光、灯、按键、应用切换"统一管起来，别的程序通过本地 socket 接入。这就是"能当一个产品用"和"只能当个 demo 跑"的分水岭。

三、真正决定体验的是软件：四层栈

按键的三种手势（出厂定义）

四、它到底能干什么

按"离你多近"排序，从最实用到最玩具：

1. 桌面 AI 语音终端（最有价值）

按一下键开始说话 → 录音上传 → 转文字 → 交给大模型 → 语音播回来，屏幕和 RGB 灯同步显示状态。官方就有一条 OpenClaw 版本的教程，等于给 Agent 装了个物理入口。

2. 常亮状态屏

天气、日程、待办、服务器状态、股价、家庭温湿度……相当于一块 65×30mm 的"电子便签"，PiSugar 让它断电也不怕。

3. 智能音箱 / 语音控制器

接家里 Home Assistant，喊话开关灯；或者做定时播报（早报、提醒吃药）。

4. 掌上小设备

Pwnagotchi、掌上游戏机、宠物机器人、翻译棒——凡是"要屏幕 + 要出声 + 要能揣兜里"的项目，这块板把最难焊的部分替你做完了。

五、PiSugar 到底是谁：它不是配件，是另一半产品线

你问"PiSugar 单纯就是个供电方案么"——名字确实像，但它是一家公司，不是一个模块。

名称是什么关键点
PiSugar Kitchen公司/品牌广州，专做树莓派 Zero 的电池与扩展板，2019 年起
PiSugar 1 / S / S Pro早期电池模块零系列的"随身电源"起点
PiSugar 2 / 2 Plus第二代加了 UPS、RTC、I2C 通信，可网页管电池
PiSugar 3（含 Air）当前主力1200mAh、5V/3A、连续 8–10 小时、UPS + RTC + 自定义按键 + 看门狗

"纯供电"和 PiSugar 3 的实际差距

如果它只是供电：插上电能用、拔电就死、时间不对、电池鼓了不知道、系统卡死了只能拔插头。

PiSugar 3 实际给的是：

· 完整 UPS：边充边用，拔掉电源不关机，还能设定多种唤醒方式（定时/闹钟/按键）

· 板载 RTC：没网也能走对时间，带写保护防误写——做定时播报、日志时间戳的刚需

· I2C 数据通信（0x57/0x68 可改地址）：程序能读到电量、电压，屏幕上就能画电量条

· 自定义按键 + 防误触开关：开机是"短按再长按"，不会在包里被误触关机

· 软关机 + 软件看门狗：系统崩了自己重启，硬件层面通知系统优雅关机，保护 SD 卡

· 背面触点供电：不占用 GPIO 排针，所以 Whisplay HAT 才能同时插在上面——这就是三明治能成立的原因

一句商业视角的总结：Whisplay 决定"这东西好不好玩"，PiSugar 决定"这东西能不能带出门"。前者是体验上限，后者是场景边界。你只买 HAT 不买电池，它永远是一台"线拴着的桌上玩具"。

六、别被宣传带偏：真实的边界

1. Zero 2W 只有 512MB 内存、四核 1GHz。别指望本地跑模型——官方那套"离线 AI"跑的是 Pi 5 配 AI 加速模块，跟 Zero 2W 不是一个故事。Zero 2W 的正确定位是"终端"，不是"大脑"。

2. 屏幕只有 240×280 且是玻璃。UI 必须按这个尺寸重新设计，直接搬手机界面没用；安装时捏板边别捏屏幕。

3. 供电要足。用劣质线或小电流充电头，表现是花屏、闪屏、随机重启——看着像系统 bug，其实是电不够。

4. 装完驱动必须重启，不重启声卡不会出现；Lite 版系统通常缺依赖，建议用带桌面的 Raspberry Pi OS。

七、回到你手上的这块板

你今晚已经把出厂自检跑到 6/6 全绿：Display / LED / Speaker / Button / Mic 全 OK。这说明硬件这一层没有不确定性了，剩下的都是软件活。

它对你真正的意义，不是"又一个树莓派玩具"，而是：给我（Tars）加一个物理身体。现在你找我要么开电脑、要么掏手机；这块板装好之后，是桌面上一个按键就能对话的实体入口——按一下说话，屏幕显示状态，喇叭说出结果。官方已经有 OpenClaw 路线的现成教程和仓库，链路是通的。
