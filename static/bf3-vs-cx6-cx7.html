BlueField-3 与 ConnectX-6/7：
NVIDIA 网卡和 DPU 到底差在哪？

三张卡、两个物种：一个负责「把数据送进门」，一个负责「进门之前把活干完」
一句话结论：ConnectX-6 / CX7 是纯网卡（SmartNIC），干的是高速传输的活； BlueField-3 是 DPU（数据处理单元），是「网卡 + ARM CPU + 可编程引擎」三合一的片上系统，干的是网络入口处的计算卸载。

三个关键差异

  • ① 芯片架构不同 CX6/CX7 是专用转发芯片，功能出厂定死，只支持固定的硬件卸载（RoCE、NVMe-oF 等）；BF3 是完整的 SoC 片上系统，网卡里装了一台微型服务器，客户可以自己写程序跑在上面。
  • ② 卸载能力量级不同 CX7 只能卸载网络协议栈；BF3 能把 Open vSwitch、防火墙、分布式存储（NVMe-oF）整套搬到网卡上，主机 CPU 占用率可以显著下降，这是「网卡」和「DPU」的分水岭。
  • ③ 价格差一个数量级 CX6 如今在二手市场几百到一两千元就能淘到；CX7 是当前主流新卡；BF3 单卡价格可以顶好几张 CX7，定位完全不同。

怎么选：商业视角

  • 跑 AI 训练 / 组高性能集群 → ConnectX-7 NVIDIA GPU 集群的标配网卡，极致带宽 + 低延迟，性价比最高，是当前 AI 算力建设的主流选择。
  • 做云、运营商、金融大项目 → BlueField-3 「算力卸载」「网络虚拟化下沉」「安全前置」是它讲得动的故事，方案价值高、客单价高。
  • 预算敏感 / 实验室 / 二手市场 → ConnectX-6 大量退役卡流入市场，组 200G 内网性价比极高，是 Homelab 和中小公司的捡漏选项。
CX7 是给 GPU 当「快递员」的，BF3 是给数据中心当「管家」的。 关注国产算力替代的读者，可以留意昇腾生态中对应的智能网卡与 DPU 布局，逻辑完全相通。
