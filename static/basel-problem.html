给小朋友的数学侦探故事

巴塞尔问题：为什么
1 + 1/4 + 1/9 + … = π²/6？

一个让数学家苦恼了 90 年的谜题，被 28 岁的欧拉用"大胆想象"解开

11²  +  12²  +  13²  +  14²  +  …   =   π²6

1先来玩一个加法游戏

我们从 1 开始，然后加上 1/4（也就是 0.25），再加上 1/9（约 0.111），再加 1/16（0.0625）……

规律是：每一项的分母是 1²、2²、3²、4²……（也就是 1×1、2×2、3×3、4×4……）。

这些数越来越小，像一块块越来越小的饼干。问题是：如果一直加下去，总数会停在哪里？

🧪 你来试试：拖动滑块，看总和怎么增长

1.000000 （目标：π²/6 ≈ 1.644934）
n = 10
每根柱子的高度 = 1/n²（第 n 个分数的"大小"），把所有柱子加起来就是总和

你会看到：不管加到多少项，总和都永远不会超过 1.645，它慢慢地、稳稳地靠近一个神秘数字——1.644934…

这个数字有个大名鼎鼎的身份：π²/6。把圆周率 π 自己乘自己，再除以 6！

2哪里奇怪？π 是"圆的"，怎么跑进"平方数"里了？

π ≈ 3.14159，它是圆的周长 ÷ 直径，是"圆"的专属数字。

而我们的问题里全是 1、4、9、16… 这些平方数，一个圆都没有，一个三角形都没有。

就像你拿做蛋糕的配方，居然算出了火箭的燃料——风马牛不相及的东西，怎么会变成同一个答案？

这正是当年全世界数学家抓狂的原因。1696 年有人提出这个问题（因为提出者来自瑞士的巴塞尔城，所以叫巴塞尔问题），结果 90 年里没人能回答。

📜 历史小故事：1735 年，瑞士一位 28 岁的年轻数学家——莱昂哈德·欧拉——宣布自己解出来了。更神奇的是，他用的方法大胆得让前辈们直摇头：他把"无穷大"当成普通的多项式来算。数学界后来花了很长时间才证明：欧拉，你是对的。

3热身：会"拆开"的多项式

欧拉破案的第一件武器，是你可能见过的"因式分解"。别被名字吓到，它其实很简单。

先看一个普通的多项式：

x² − 5x + 6 = (x − 2)(x − 3)

你可以在心里展开验证：(x − 2)(x − 3) = x² − 3x − 2x + 6 = x² − 5x + 6 ✔

注意一件有意思的事：这个多项式在 x = 2 和 x = 3 时等于 0（因为 2−2=0，3−3=0）。我们把这样的 x 叫做多项式的"零点"。

💡 关键规律：知道一个多项式的"零点"，就能把它拆成"（x − 零点1）×（x − 零点2）× …"的样子。反过来，拆开了，就知道它的每个零件长什么样。

欧拉的疯狂想法是：sin x 这种"波浪函数"，是不是也可以当做一个"无限长的多项式"来拆？

4认识 sin x：一条会画波浪的曲线

sin x 是三角函数家族的一员，它画出来的图像像大海的波浪，上上下下，永远不停（角度用"弧度"来量，一圈是 2π ≈ 6.28）。

sin x 的图像：波浪在 x = ±π、±2π、±3π …… 处穿过 x 轴（红点），这些就是它的"零点"

注意看红点：sin x 的零点在 ±π, ±2π, ±3π, ±4π ……，一个接一个，像路灯一样均匀排列。

如果 sin x 真是"无限长的多项式"，那它的零点这么多，拆开来的因式也得有这么多！

5欧拉的破案现场（四步推理）

第 1 步：把 sin x 写成"无限长的多项式"（这叫泰勒展开，欧拉时代的前辈们已经会了）：

sin x = x − x³3! + x⁵5! − x⁷7! + …
📌 小知识：3! 读作"3 的阶乘"，意思是 3×2×1 = 6。所以 3! = 6，5! = 5×4×3×2×1 = 120。

两边都除以 x（这样更方便，因为 x² 的"位置"会更明显）：

sin xx = 1 − x²6 + x⁴120 − x⁶5040 + …

（注意：x³ ÷ x = x²，x⁵ ÷ x = x⁴，依此类推。以后我们只关心 x² 前面的那个数，它叫"x² 的系数"，这里是 −1/6。）

第 2 步（大胆假设）：普通多项式按零点拆开，sin x 也照做！sin x 的零点在 ±nπ（n = 1, 2, 3, …），所以：

sin xx = (1 − x²π²) × (1 − x²(2π)²) × (1 − x²(3π)²) × ……

检查一下：当 x = π 时，第一个括号里是 1 − π²/π² = 0，整个乘积变成 0 ✔。当 x = 2π 时，第二个括号归零 ✔。每个零点都被"照顾"到了！

第 3 步（展开找 x²）：把右边乘开。想得到 x²，就要在其中一个括号里取"−x²/(nπ)²"这一项，其他括号都取 1（因为两个括号都取 x² 就变成 x⁴ 了，太"高"了）。所以：

x² 的系数 = −1π² − 1(2π)² − 1(3π)² − … = −1π² × (1 + 14 + 19 + 116 + …)

第 4 步（对答案）：同一个"人"（sin x / x），x² 的系数必须是一样的！

  • 从第 1 步知道：x² 的系数 = −1/6
  • 从第 3 步知道：x² 的系数 = −(1/π²) × (1 + 1/4 + 1/9 + …)
  • 两边相等：−1/6 = −(1/π²) × S （S 就是我们的总和）

解这个方程：两边都乘 π²，再乘 −1，得到 S = π²/6。

1 + 14 + 19 + 116 + … = π²/6 ≈ 1.644934

侦探结案！🔎

6怎么知道欧拉没算错？

刚才你亲手拖了滑块：加到 200 项时，总和已经非常接近 1.644934。而 π²/6 = 3.14159² ÷ 6 ≈ 1.644934。

两个完全不同的计算路径，撞出了同一个数字——这不是巧合，这是真相。

不过，欧拉的"无限多项式当普通多项式拆"在当时太超前了，很多数学家说："等等，这能随便拆吗？" 后来一代又一代数学家严格证明了：欧拉是对的。数学就是这样：先大胆猜，再小心证。

7这个答案有什么用？（物理彩蛋）

💡 光的亮度

离灯泡越远，光越暗，亮度按"距离的平方"衰减。把一排小灯泡的亮度加起来，就会冒出 π²/6 这个数。

🔊 声音的传播

声音能量也按距离平方衰减。音乐厅里混响的"叠加"计算，和平方倒数之和一个道理。

🌉 桥梁的震动

工程师研究桥梁被风吹动、被脚步踩动时，也常常遇到"1/n² 求和"——原来 π 藏在工程里。

🎲 欧拉后来还算了

1 + 1/16 + 1/81 + … = π⁴/90 ≈ 1.0823。同样的方法，威力无穷！

8一句话记住它

把 sin x 当成一个"零点在 ±nπ 的无限多项式"来拆开，再看 x² 前面的数——平方数的倒数之和 = π²/6。

数学家欧拉用"大胆想象 + 小心验证"，把圆的秘密和数字的秘密连在了一起。下次看到波浪、看到 π，别忘了这里面可能藏着平方数的故事哦。🌊
