01Agent Skills 正在标准化

Anthropic 于 2026-10-22 把 Agent Skills 标准捐给 Linux 基金会下的 Agentic AI Foundation。这不是一个仓库的转移，而是把「可复用的 Agent 操作流程」交给基金会维护。

Anthropic 自称已有 70 多家平台接入，包括 ChatGPT、Cursor、GitHub Copilot、VS Code；并称有「100 万个已发布技能、近 2.8 亿次安装」。后两个数字是官方口径，没有独立审计。

Google 开源博客 2026-11-11 确认，Google、Anthropic、OpenAI 的工程师在该基金会下共同维护 Skills，并与 MCP 分工：MCP 管实时工具，Skills 管按需的操作流程。Google 同时承认，打包、发现和版本管理还没有定标准。

02审查与安全成为付费层

Agent 产出越来越便宜，审查反而成了瓶颈。周榜上出现了一整排工具：

  • backnotprop/plannotator：人工审 Agent 计划与代码，13,272 星，本周 +2,926。
  • alibaba/open-code-review：Go 编写，确定性流水线加模型代理，行级评论，内置空指针、线程安全、XSS、SQL 规则；54,088 星，本周 +3,675。
  • openai/codex-security：14,042 星，本周 +2,531。
  • NVIDIA/SkillSpector：Python，扫描技能中的恶意模式、提示注入和供应链风险；26,716 星，本周 +1,430。

elementalsouls/Claude-BugHunter 是同周脉冲：10,447 星，当日 +2,322、本周 +2,508。它是 Claude Code 的漏洞狩猎技能包，不是新的推理引擎。

Hacker News 上有一条「哈佛研究者发现 AI 编程代理把瓶颈转到代码审查」，当时约第 17 位、207 分、287 条评论。原文未读，不引用其中的百分比。

微软在 2026-11-17 发布 MAI Code 2 / Code 2 Flash，这是 GitHub Copilot 里的闭源编码模型，不是开源权重，只构成价格压力。

商业含义：Agent 产出已经便宜，能合并、可审查、没有夹带私货的产出才稀缺。

03推理栈：兼容与硬件可移植

llama.cpp / ggml v1.0.0

2026-11-13 10:20 UTC（北京时间 18:20）发布。官方 Hugging Face 博客称这是带语义化版本的稳定公共 C API/ABI。发布说明还包括 OCP FP8 KV cache、可配置 CPU 占比的主机内存 MoE 专家缓存、新架构 Kimi-K3.1-Pro / Ripple-65B-Preview / xing4_0、drama-3 TTS、Kimi-K3.1 视觉、llama-server 加固，以及 /v1/audio/speech。GitHub API 当时为 135,626 星，当天有推送。

vLLM 0.34.0

2026-11-16 23:22 UTC（北京时间 11-17 07:22）发布：1,061 次提交、412 名贡献者。默认可扩展 KV cache，发布说明举例 MiniMax-M3 在 H200 上从 433k 增至 672k tokens。移除 Model Runner V1；默认 --block-size 改为 64（原 16）；gpu_memory_utilization 默认 1.0；ROCm 7.2 制品改为只提供 ROCm 10.0。

新模型支持包括 Mistral Large 4（Blackwell/Hopper 与 AMD MI350 上的 FP8/NVFP4）、MiniMax-M3.1-Flash、Ripple-65B Preview，以及若干 NVIDIA 语音模型。项目自称 GB200（Step5）解码最高约 1.95×、GLM-5.3-Flash 吞吐约 1.6×；也写了代价：部分 H200 模型在并发 128 时 TPOT +6–18%。GitHub API 为 97,155 星。升级不是随手可做。

SGLang v0.5.23

2026-11-02，当时能确认的最新标签：DeepSeek-V4.1 在 GB300 上的 prefill / 首 token 数字、可选的 NVIDIA megakernel / AMD monokernel、大于显存的 MoE 专家分页、TPU7x 路径。官方镜像覆盖 CUDA 13、ROCm 10 MI35x/MI30x、Intel GPU/CPU 和 TPU。

Ollama v0.40.16

2026-11-09，发布页 HTTP 200。加入 Ripple Preview、Qwen3.8 Flash Next 在苹果芯片上约减少 27 GiB 内存、Windows on ARM 的 CUDA 13.5，以及 llama.cpp 更新；v0.40.17 仍是 rc。GitHub API 为 187,514 星。

vllm-project/vllm-ascend 出现在 Python 日榜，但当日只 +13 星（共 3,106，当天有推送）。这是仍在维护的华为昇腾插件，不是炒作。

商业含义：利润在内核、量化（FP8、NVFP4、MXFP4）和非英伟达后端；升级有代价。

04开源权重已在 10 月底–11 月初落地

这一周没有新的 Llama 开放。权重这波是 10 月底到 11 月初已经落地，本周发生的是推理框架补支持。

Mistral Large 4（“Le Chonk”）于 2026-10-29 放出权重：约 1 万亿总参数 / 520 亿激活 MoE，多模态，100 万上下文，FP8 与 NVFP4，可用 vLLM 或 SGLang 部署，也有 NVIDIA NIM/TensorRT-LLM 配方。官方 API 定价：$0.70 / 缓存 $0.07 / $2.10 每百万 tokens。许可证是改过的 MIT：可使用、修改、微调、商业化，但模型即服务运营商需另签商用许可。

公司自称分数（未独立复跑）：FrontierCode 2.0 19.7%；Artificial Analysis Coding Agent Index 48%，与 GLM-5.3 的 47% 相比用更少 token；Terminal-Bench 4.0 41%。Hugging Face 博客正文有一处写过 49B，部署仓库名是 Mistral-Large-4-1T-A52B，本页采用 520 亿激活，不写成已复验。

DeepSeek-V4.1-Flash-1017：Hugging Face，MIT，7630 亿参数，100 万上下文；模型卡写 Terminal-Bench 4.0 为 42.3、DeepSWE v1.1 为 77.0（相对前一版 Flash）；合集页显示 Updated Oct 17。

Moonshot Kimi-K3.1-Pro：2.8 万亿总参数 / 1040 亿激活，100 万上下文，MXFP4 权重 / MXFP8 激活，MoonViT-V2，模型专用许可；llama.cpp v1.0 已加架构。18 日打开时 HF 合集写 “Updated 12 days ago”（约 11 月 6 日）；未在模型卡上找到带日期的官方发布稿，不能写成已确认的精确发布日。

QwenLM/qwen-code 仍在 TypeScript 周榜（30,746 星，本周 +1,603），是开源终端编程助手，不是这一窗口的新 Qwen 权重。

商业含义：能下载的万亿级编程模型已经有了，约束是集群、许可和服务软件，不是拿不到权重。端侧和小模型仍走 llama.cpp / Ollama，不是这些巨型检查点。
