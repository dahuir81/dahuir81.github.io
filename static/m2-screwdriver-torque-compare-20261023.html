二、M2 螺丝：为什么最低档才是关键

先定标准：M2 在塑料里约 0.3 N·m

  • Freefly 工业扭矩规范：M2 标准紧固件 0.3 N·m（M1.6 = 0.2，M2.5 = 0.4）
  • PEM 自攻嵌件数据：M2 在 ABS 中约 0.3 N·m
  • NBK 塑料螺丝规格书：M2 破坏扭力 0.055 N·m，明确要求「拧紧扭矩取其 50%」——这是塑料螺丝最极端场景

综合：3D 打印件 + M2 自攻，安全区间 0.15–0.35 N·m；超过 0.5 进入滑牙 / 撑裂高风险区。

PivotDrive 的 ¥394 值得单独说：
好的一面：9mm 偏轴伸进结构件凹槽、4 角度自锁（0/30/60/90）、2000mAh、180 转低速。
问题：415g 偏重、充电 3 小时、扭矩下限 0.5。
结论：它是「能伸进死角的家装级起子」，不是 M2 精密起子。¥394 买它不亏，但别指望它替代 S-A01。

三、打磨机：结论修正

前一版结论是「不建议买打磨机」，理由是「表面抛光不该上机器」。那个判断的前提错了。

你真实的场景是「修边缘」，不是「抛光表面」

活工具转速
去毛刺（平整面）刻刀 / 刮刀 ✅ 你已经在用—
修边缘、倒角、磨平凸起电磨 ✅ 对口的工具中低速
恢复光泽抛光膏 + 布轮极低速

为什么刻刀修不平边缘：刀只能「切」，不能「磨」。边缘溢料、层纹错位造成的台阶，刻刀一削就崩边或留坑。这种活确实需要旋转磨头。

所以：四件套已下单，不后悔，也不用重新下单。
打磨机在你「刻刀修不平的边缘」这个场景里是对口的工具。

但要注意：砂纸会让表面失光，这不是用错了

FDM 件的光泽来自层纹的规则反光。砂纸把层纹磨成随机划痕 → 反光变散射 → 看着发白。磨这个动作本身就破坏光学特性。

电磨转速更高（15,000–22,000 RPM），不只是失光，还可能局部摩擦生热熔出亮疤。WIRED 实测 R-A04 就是「过热快、用久掉速」。

实操：避免熔疤的四个动作

  1. 从最低档 15,000 起步，不直接用最高档
  2. 「点焊式」操作——点一下、抬起、再点下一处，绝不在一个点停留
  3. 用圆柱/圆锥磨头（接触面积小、散热快），避免球形和砂纸圈
  4. 电磨修完用 800 目砂纸轻收，过渡更自然
最高效的试错方式：打一个「测试方块」。
同参数打一个小方块，专门拿来试不同转速、不同磨头、停留多久会熔。几分钟就能摸清这台机器的脾气，比在成品上慢慢试安全得多。换材料（PLA→PETG）就重打一个。

四、电烙铁：决策取决于 X1 的处理路径

说明：我没有读到 air 上 DSH / Codex 关于 X1 的实际处理记录（跨机 SSH 通道不通）。下面是基于公开技术资料的判定树，你按自己机器的实际状态对号入座。

X1 救砖的公开方法论（X1 PRO 研究站）

第 1 步 · 不拆机
按键组合进 9008 模式
高通紧急下载模式。不需要焊接，不需要烙铁。
第 2 步 · 拆机短接
9008 按键进不去 → 拆机短接主板两点
用镊子让两个测试点接触，强制进下载模式。需要的是螺丝刀 + 镊子，仍然不需要烙铁。
第 3 步 · 才是焊接
短接点太小 / 接触不良 → 飞线
只有这一步才需要烙铁。而且要焊住 0.2mm 级别的线，这是精密焊接。

判定表：三种情况，三种买法

X1 现在的情况是否需要烙铁该买什么

按键进不去，准备拆机短接不需要精修螺丝刀 + 镊子（¥50）

为什么「精密飞线」不该用便携笔：
HOTO I-A06 无线状态只有 60W（有线 140W），415g 握持没有固定支架。焊 0.2mm 飞线需要「板子固定 + 手稳 + 温度精确」，这正是便携笔最弱的三点。
飞线这种活，台式焊台 + 尖头 C245 才是正解。

理由不是它性能更好，而是你还在「被引导」的学习阶段——焊不熟这件事，用 ¥250 和 ¥450 的工具犯的错没有区别。
等真焊到「60W 回温跟不上」的时候，你自然知道该升级什么。

六、三句话收尾

  1. 螺丝刀看下限，不看上限。 最低档必须 ≤0.35，最好能到 0.1 以下——这条卡死了 PivotDrive 和博世。
  2. 打磨机修边缘是对的，毁表面是必然的。 别在同一件东西上又磨又要求光泽，这是两套工艺。
  3. X1 大概率不需要烙铁。 短接是用镊子，不是用焊枪。真到飞线那一步，再买台式焊台，别用便携笔。
