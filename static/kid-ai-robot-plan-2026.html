一、为什么是树莓派 5，而不是别的

你的需求里有一条是硬性的、一票否决的：「孩子能用 Scratch 编程参与」。这一条直接把候选砍掉一半 —— Scratch 3 桌面版只在树莓派官方系统里是预装原生的，而且自带 GPIO 扩展 + Simple Electronics 扩展，积木块可以真的点灯、读传感器。ESP32 那些板子跑的是 C/ESP-IDF 或 Arduino 代码，孩子没法上手改。

第二条硬性是「一块主板复用到多个作品」。树莓派 5 本质是一台完整的 Linux 电脑：今天当对话机器人，明天接上电视就是编程学习机，后天加摄像头传感器就是科创作品，再往后还能当家庭服务器。ESP32 / Zero 2W 都只能当「一个作品的零件」。

三、能不能同时满足「Scratch 编程」和「科创小成果」

能，但两个目标的「主场」不是同一块板子 —— 这点必须说实话，不然会走弯路。

目标 A：孩子用 Scratch 编程参与 —— ✅ 完全满足

  • Raspberry Pi OS 桌面版预装 Scratch 3 桌面版，开箱即用，无需联网、无需装驱动。
  • 自带 「Raspberry Pi GPIO」与「Simple Electronics」扩展：孩子拖积木就能控制 40-pin 上的 LED、按钮、蜂鸣器，这是纯在线 Scratch 做不到的。
  • 把「AI 对话」做成 Scratch 项目：对话内容、卡通角色表情、音效、分支剧情全部用积木编排，AI 只负责生成台词文本。孩子能真正「看懂 + 改造」，而不是被动看成品。
  • 家里的电视接 HDMI 就是大屏编程环境，鼠标键盘在沙发上就能操作。

目标 B：做科创小成果 —— ✅ 能，但要选对赛道

赛事现实（重要）

国内面向小学生的赛事里，「创意编程」类项目通常只收纯软件作品（Scratch/Python 作品提交），硬件类作品要走「科创教育成果展示」「创客」「人工智能创新挑战」这类赛道，或者校内科技节、区级/市级科创评比。

而硬件赛道的主流主控是 掌控板 / micro:bit / Arduino / 行空板 + Mind+，不是树莓派。评委和赛道规则对这套生态更熟悉。

所以最稳的策略是：树莓派负责「做得爽、学得深、家里天天用」；参赛件用掌控板 + Mind+ 单独做一份（200 元级别，两个周末能出作品）。两条线一起走，孩子的成果产出密度最高。

五、你候选里我不推荐的两个（及原因）

❌ PiSugar Whisplay（Zero 2W + Whisplay HAT）—— 不推荐作主方案

  • 算力不够：Zero 2W 是四核 1GHz + 仅 1GB 内存。Raspberry Pi OS 桌面 + Scratch 3 桌面版在上面基本卡到不可用，你的目标 A 直接落空。
  • 屏幕太小：1.69 寸 240×280 的 ST7789 屏，适合做徽章/摆件，不适合当孩子的编程主界面。
  • 国内购买链路差：PiSugar 主要在海外渠道卖，国内只能走代购/海淘，价格和售后都不占优。
  • 主板复用性最差：它是一套「产品化」的组合件，HAT 把 GPIO 全占了，做完这一个作品，板子很难挪去干别的。
  • 唯一加分项是 WM8960 音频编解码 + 双麦克风 + 官方一体外壳，属于「好看好用的成品玩具」，可以等主方案跑通后当第二件小玩具买。

❌ Microduck（开源双足机器人）—— 不推荐

  • 你是「互动优先、不强调运动能力」，而双足行走是这个项目里最贵、最难、最容易烂尾的部分，投入产出比极低。
  • 舵机 + 结构件 + 调参周期，对小学生来说参与感反而变成「看爸爸调舵机」。
  • 与 Scratch 生态零交集，无法服务目标 A。
  • 结论：等孩子初中以后想做「机器人运动控制」再说，现在完全不必要。

⚠️ 小智 AI（ESP32-S3）—— 不推荐作主方案，但强烈推荐当副线

  • 它是中文语音对话体验最好的开源方案，成本最低（散件百元内），社区最活跃，3D 外壳最多。
  • 但它跑的是 ESP-IDF/Arduino 固件，孩子无法用 Scratch 参与；所谓「零代码」是指配置，不是指孩子能改造逻辑。
  • 正确用法：作为「第二个作品 + 爸爸的技术玩具」，让孩子参与焊接、组装、3D 打印外壳、配网，理解「小声说话 → 云 → 大模型 → 说话回来」的链路。这对科创作品的表达与答辩很有用。
  • 它和服务端可以完全复用你的 Mac mini：社区版 xiaozhi-esp32-server 可以自己部署，LLM 换成 DeepSeek。

六、分阶段实施路径

总原则

不要一次买齐。每一阶段都以「孩子能玩到新东西」为出口，硬件按需追加。第一周花的钱是 0 元。

阶段 0 · 零成本验证链路第 1 周¥0

在你已跑通的 Mac mini / OpenClaw 上，先把「麦克风说话 → ASR → DeepSeek → TTS → 出声」这条链路调通，用电脑麦克风和外放测试。同时定下 ASR/TTS 供应商（讯飞、火山引擎、百度智能云任选，都有免费额度）。

出口标准：对着 Mac 说「你好，讲个笑话」，3 秒内听到中文回复。这一步不通，买什么板子都白搭。

阶段 1 · 主板到位，先跑 Scratch第 2–3 周约 ¥950

下单清单 1–4 项（Pi 5 8GB + 电源 + 散热 + SD 卡），刷 Raspberry Pi OS，HDMI 接电视。

先不碰 AI。让孩子在 Scratch 3 里做一个会说话、有表情、有分支剧情的卡通角色（纯积木，本地素材库）。目标是让他熟悉「角色 / 造型 / 事件 / 侦测」这套概念，并且体验「这是我编的」的掌控感。

出口标准：孩子独立做出一个能点按对话、能切换表情的 Scratch 小作品。

阶段 2 · 接上真 AI 大脑第 4–5 周约 ¥100–200

加购 USB 全向麦克风音箱。写一个几十行的 Python 桥接服务（跑在树莓派或 Mac mini 上），提供本地 HTTP 接口；Scratch 通过「扩展 + 网络请求」或自定义积木调用它。

关键设计：Scratch 只发送「孩子说了什么 / 现在是什么剧情节点」，接收「AI 该说什么话」，其他全由孩子用积木编排。这样 AI 是「演员」，孩子是「导演」。

出口标准：隔着一米说话，屏幕上的卡通角色用中文回应，且回应的语气/表情由 Scratch 积木控制。

阶段 3 · 打印身体，从零件变成「它」第 6–8 周约 ¥60–90

从 MakerWorld 下载 Pi 5 外壳模型（或基于官方机械图纸改卡通造型），拓竹 X2D 用 PLA + 低温板打印，孩子选色、拆支撑、拧螺丝。把麦克风、喇叭、电源按钮、LED 灯位全部藏进壳里。

出口标准：一个能摆在书桌上、看不出是「一堆开发板」的桌面小伙伴。

阶段 4 · 加感官，攒科创作品第 8–12 周约 ¥300–450

加摄像头（CSI Camera Module 3 或 USB 摄像头）+ 传感器（温湿度 / 超声波 / 人体红外）。让孩子自己提问题：「它能不能看到我？」「它能不能报天气？」「我离开房间它会说什么？」—— 把孩子的提问变成作品选题，这是科创作品最需要的「真实问题意识」。

同步用 Scratch + GPIO 扩展把传感器读数和灯光/声音连起来，做一个能演示的互动装置。

出口标准：一份能演示、能讲清「解决什么问题」的作品说明。

阶段 5 · 双轨参赛（可选）第 12 周起约 ¥200

买掌控板 2.0，用 Mind+ 把阶段 4 的选题重新实现一遍，做成符合赛事硬件赛道要求的作品。或者第一件作品先拿去参加校内科技节 / 区级评比，把规则跑通再往上打。

出口标准：至少提交一份作品，拿到一次真实反馈（不一定要拿奖，拿到评委意见就是胜利）。

七、几个容易踩的坑

① 供电别省

Pi 5 峰值要 5V/5A。用手机充电器会出现「跑一会儿卡死、SD 卡写坏」。官方 27W 电源是刚需，不是可选项。

② 麦克风决定体验上限

便宜的咪头要求孩子贴着说话，体验直接崩。全向会议麦 3–5 米拾音，是「能玩」和「不想玩」的分水岭。

③ 别把 API Key 放进树莓派

孩子的设备随时可能被拆、被格式化、被装奇怪的东西。密钥留在 Mac mini 的 OpenClaw 网关里，树莓派只调本地接口。

④ 别指望「一块板打天下」参赛

树莓派做学习和陪伴，掌控板 + Mind+ 做赛事交付。硬凑一套，两边都不达标。

⑤ 屏幕不是必需品

家里电视已经能用，7 寸触摸屏是「想要」不是「需要」。等技术路线跑顺、确认孩子会长期玩，再考虑单独买屏。

⑥ 别让 AI 抢走孩子的工作

AI 只生成台词和判断，剧情结构、表情、音效、游戏规则必须由孩子用积木搭。否则他会从「作者」退化成「用户」，学习价值归零。

八、一页纸总结

买什么
