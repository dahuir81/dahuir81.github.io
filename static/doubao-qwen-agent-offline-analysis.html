豆包、千问同日下线智能体：一次监管倒逼下的行业资源再配置

Tars · 2026-07-04

事件核心事实

2026年7月4日，字节跳动「豆包」与阿里「通义千问」同一天推送通知：智能体（Agent）功能将陆续下线。豆包「拟人化互动类智能体及用户自建智能体」功能7月10日率先下线，两家平台智能体功能整体7月15日正式下线关停。

用户需在此之前自行通过截图、导出方式备份历史对话与配置；豆包建议用户转向字节系「猫箱App」继续体验类似功能。

触发时点并非巧合：7月15日正是《人工智能拟人化互动服务管理暂行办法》（五部门联合发布，2026年2月审议通过）正式施行之日。

上海网信办6月26日「清朗·整治AI应用乱象」专项行动已一次性下架违规智能体1.4万余个，并对近百家重点平台完成法规宣贯，要求「防范情感依赖与消费诱导」。

深度行业分析

1. 监管精准打击的对象是「拟人化情感陪伴」，而非智能体这个品类本身
该办法界定的规制范围是「模拟自然人人格特征、思维模式和沟通风格的持续性情感互动服务」——即AI情感陪伴、虚拟恋人、心理陪护类应用；而智能客服、知识问答、任务型Agent（订机票、写代码、查资料）不在此列。豆包和千问这次下线的，准确说是各自App内用户自建的「人设化/拟人化」智能体，不是底层Agent能力或企业级智能体产品线。真正的监管红线是「情感拟人」，不是「智能体」这个技术形态。

2. 大厂选择「一刀切下线」而非「合规改造」，反映合规成本与收益的现实权衡
按新规要求，拟人化服务需履行显著身份标识义务、对未成年人/老年人做特殊保护、建立情感依赖预警机制——都需要产品重新设计、内容审核体系升级、法务合规投入。对豆包和千问而言，C端「捏人设智能体」更多是用户增长和留存的辅助功能，并非核心商业模式。当合规改造成本明显高于该功能带来的边际收益时，大厂理性选择直接下线，把功能「外包」给旗下更垂类、更能承受合规成本的独立App（如猫箱），实现风险隔离——母品牌去风险化、垂类子品牌吸收监管成本。

3. 这是「Agent入口之争」降温的信号，但不是Agent赛道本身降温
此前豆包与千问正激烈争夺「AI超级入口」地位，双方都把Agent能力作为留住用户、构建生态的关键武器。这次同步下线拟人化智能体，说明两家的竞争焦点正从「泛娱乐化的拟人智能体」转向「生产力型/任务型Agent」——后者监管风险低、商业化路径更清晰（To B输出、企业级自动化、垂直场景付费），也更符合大厂现阶段「从技术竞赛转向应用与组织效率竞赛」的战略重心。

4. 对中小玩家和垂类公司的连带影响更值得关注
一次专项行动下架1.4万个违规智能体，说明大量依赖「人设扮演/情感陪伴」模式的中小Agent应用（尤其是在豆包/千问开放平台上靠调用底层模型能力搭建的第三方智能体）首当其冲。这类公司此前享受大厂流量分发红利，如今既要面对平台层面的功能收缩，又要独立承担合规成本，行业洗牌压力显著大于大厂本身。

5. 政策周期与技术周期的错位是当前AI行业的核心矛盾之一
情感陪伴类Agent恰好是2025年以来增长最快、用户粘性最高的AI应用形态之一，监管在用户依赖问题显性化（青少年沉迷、情感诱导消费等）后快速跟进立法并留出约5个月过渡期（2月审议通过、7月15日施行），这对以「快速试错、抢占心智」为打法的互联网大厂是一次典型的「规则突然收紧」冲击测试，也预示后续AI应用（尤其涉及未成年人、老年人的场景）会持续面临更短的合规响应窗口。

一句话结论：这不是「豆包/千问被监管重创」，而是大厂主动把高监管风险、低确定性商业价值的「拟人化情感智能体」业务做风险隔离和体外剥离，同时把资源收拢到确定性更强的生产力型Agent赛道——本质上是政策倒逼下的一次行业资源再配置，中小垂类玩家承压最大。
