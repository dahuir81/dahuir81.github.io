跑分涨了，口碑为什么劈成两半

官方口径是“性能–费用的帕累托改进”，榜单也确实全面上涨；但翻一遍主流实测，画风立刻分成两派：一边喊“前端世一、斩杀线”，一边说“3D 抽象、长程翻车”。这篇不站队，把两边的话摆在一起看。

结论：这是一次“工程指标型”升级，不是能力跃迁。日常编码、Agent 工具链、网页还原确实更强更便宜；但复杂 3D、长程自主、审美细节这些真正拉开差距的地方，主流实测并没有跟着跑分一起涨。把它当高性价比工人可以，当“一次交付的大师”会失望。

02

舆论场：三种声音，各说各的

同一天、同一个模型，B 站标题在“震鲸瘫坐”，公众号在“还是难评”，知乎在“审美离第一梯队还有差距”。这不是谁撒谎，而是测试集和期待值完全不同。

吹爆派：前端和单页确实能打

B 站测评区 / X 部分博主

V4.1 Flash 1017：前端能力世一拉爆 Opus 5？震鲸瘫坐鹈鹕骑车、樱花电车，效果惊人

他们的用例集中在：单页前端、SVG/Canvas 动画、网页复刻、短平快的“一句话生成”。这类任务正是 1017 提升最明显的地方，出片效果也确实抓眼球。

泼冷水派：复杂 3D 和长程照样翻车

公众号实测《DeepSeek 新版，还是难评！》

桥的摆放位置和角度不对座椅插到屁股了，腿折了坦克在地上打滚，左右还反了

五个偏难的“许愿式”案例里，只有网页复刻和开局界面算过关；3D 车库做了 3 小时，效果提升有限。作者的原话：不是不让你等，是等久了效果还不好，就比较痛苦。

理性派：进步在工程指标，不在审美和世界知识

知乎测评 / 开发者社区

知乎高赞测评的判断很克制：综合审美能力比 V4 各版本显著更高，但离第一梯队还有差距；对间距、配色、复杂高级建模、动效、转场，表现还不及预期；Agent Coding 提升幅度有限，略好于前代 Pro。另有开发者反馈：拿它替大模型跑数据清洗，前几轮很稳，长会话后半段会把字段名偷偷改掉，最后仍要人工兜底。

为什么差这么多？三个变量：①用例——单页前端 vs 多文件 3D 工程，难度不是一个量级；②档位——max 档更啰嗦也更慢，low/high 档体验完全不同；③Harness——官方明确针对 DeepSeek Harness 0.2.1-rc.1+、CodeBuddy、WorkBuddy 优化，换个壳子跑，成绩会掉。再加上流量标题天然偏爱“世一/斩杀”，差评天然更具体——两边都不能全信。
03

官方这次到底改了什么

  • 训练：基于自反馈的强化学习，重点补“从零搭完整项目”，官方称之为“许愿式编程”。
  • 效率：任务运行时间与输出长度同时缩短，价格不变，才构成“帕累托改进”。
  • 适配：针对 DeepSeek Harness、腾讯 CodeBuddy / WorkBuddy 专项优化，Harness 需 ≥ 0.2.1-rc.1。
  • 同日第二件事：开放自研搜索 API（Search / Fetch），千亿级网页索引，主打反 SEO 作弊与低质 AIGC。
  • 计费：各 5 元 / 千次成功请求；Harness 内调用目前免费，2026-11-1 起收费。
  • 接入：模型名仍是 deepseek-flash，网页端与 App 已同步，旧模型名自动路由到 1017。
04

实测案例：五个“许愿式”任务

来自公众号逐项实测。例子偏难，失败不代表日常任务不行，但能看清天花板。

赛博上河图
明显进步

空间层次、建筑轮廓、远山剪影和河里那条“大肥鱼”都出来了，河岸房屋与柳树更精致。硬伤：桥的位置和角度不对，一眼假。

天文机械表
仍不合格

功能能跑，但表盘线条怪异、秒针透明、两个小表盘含义不明。对比之下，GPT / Claude 新一代能干净处理，连 Haiku 5.5 都不错。

超级玛丽
反而退步

跳跃逻辑出问题，后半张地图全乱。它没去查资料，直接“脑补”——提示词允许它自信，它选择了盲目自信。

甲维斯的车库
一半合格

网页复刻到位：布局、配色、控件基本还原。3D 建模依旧抽象——座椅穿模、腿折、汽车轮廓乱。耗时约 3 小时，大半花在自我验证。

坦克世界
大幅进步

开局界面很有感觉，UI 与基本结构都在。进场后坦克满地打滚、左右操控反向，离 3A 差得远；作为“搞笑游戏”倒是合格。

06

到底该怎么用

可以放心交给它

  • 仓库级重构、CI 排障、多轮工具调用的编码 Agent
  • 网页/DOM 复刻、单页前端、SVG/Canvas 动画
  • 图像理解 + 文档流水线（原生多模态）
  • 高并发、成本敏感的批处理（并发 2500）

必须人盯人

  • 大型 3D 场景、精细道具建模
  • 数小时自主规划的长程项目
  • 对间距、配色、动效苛刻的交付
  • 长会话后段容易指令漂移，需阶段校验

一句话选型：把它当“高频主力工人”，不是“一次交付的大师”。任务在能力圈内，它是当下性价比最锋利的那把刀；超出圈子的活，拆小、加校验、人兜底。

值不值得换：已经在用 deepseek-flash 的，零成本升级；只在跑重 3D / 超长自主任务的，先小样本复测再放量。别拿榜单当验收标准，拿你自己那三个最难的用例当标准。
