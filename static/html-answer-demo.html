14 人团队、不做 App、不向用户收费，只靠短信和电话替人办事的 Instinct，2026-09-28 完成 10 亿美元 C 轮，估值 100 亿美元——而一个月前的 B 轮，投前估值还只有 22.5 亿美元。

结构图：它到底做了什么

入口刻意做薄：没有 App 图标，只有通讯录里的一串号码。创始人逻辑是一句话——用 AI 不该再多装一个 App。

三个反常识

  1. 不做 App。 产品只走短信（iMessage / SMS）与电话，把摩擦压到「通讯录级别」的入口。
  2. 用信任而不是榜单做壁垒。 用户使用约 3 周后约 40% 交出信用卡；交出至少一项敏感信息的人，留存约 80%。信任在这里是一条可量化的转化率，不是品牌词。
  3. 稀缺与零营销。 邀请制起步、早期只放约 200 名亲友、每人 5 个邀请码，邀请码在 eBay 被炒到约 300 美元 / 个；近期日环比约 10%–11%，营销支出近乎为零。

质疑与风险

  • 100 亿美元估值更像「品类期权」，定价对象是速度本身。
  • 算力需求约每周翻番，创始人自述约 40% 时间花在解决算力。
  • 「不向用户收费」与 Agent 可抽佣的商业模式存在内在矛盾。
  • 核心悬念：信任积累的速度，能否跑赢巨头的分发速度。
  • 泡沫语境：钛媒体等口径认为硅谷 VC 正在批量制造「纸面独角兽」，靠「双档融资」（领投方以低估值投大部分资金、同时以天价估值投小部分，对外只公布天价估值）做高账面数字。

对慧哥的参照

  • 赛道判断：个人 Agent 的胜负手已从「模型能力」转向 入口 + 授权 + 支付 三件套；「不装 App」本质是抢通讯录级入口，对国内微信 / 钉钉生态内的 Agent 有直接参照价值。
  • 可迁移指标：把「用户多久交出第一张信用卡」当作信任度量，比 DAU 更接近交易本质。
  • 风险提示：200–333 倍潜在收入倍数属速度定价，品类热度回落时估值弹性同样巨大；需区分「品类确定性」与「公司确定性」。
