01一句话结论

这是一份「增长曲线极陡 + 会计亏损极丑 + 现金极厚 + 未来承诺极重」四件事同时成立的招股书。读它的关键不是看净亏损 807 亿美元，而是要分清三层：

  • 业务层：已经跑出真实规模，且亏损在收窄（调整后经营已转正）。
  • 会计层：净亏损主要来自可转债/SAFE 因估值上涨产生的非现金公允价值变动（2026H1 达 723.9 亿美元），与经营无关。
  • 承诺层：真正的风险不在这半年的损益表，而在未来十年的算力采购与租赁承诺——招股书明确说这些现金流"重大且 2030 年前后开始集中体现"。

02发行条款与治理：一家"不按常理"的上市公司

发行结构

  • 标的：Class A 普通股，代码 ANT
  • 结构：公司发行新股 + 老股东出售（卖老股部分公司不分钱）
  • 承销团：高盛、摩根士丹利、摩根大通领衔，花旗、巴克莱、美银、德银、RBC、UBS 等 20+ 家
  • 锁定期：创始人及大股东最长至 2027 年 Q3 财报后第二个交易日，或招股书后第 365 天；其他股东 180 天
  • 注：招股书为"Subject to Completion"版本，发行股数与价格区间留白

四类普通股，权力分层

  • Class A：1 股 1 票，可公开交易
  • Class N：无投票权但有经济权；主要发给战略伙伴（Amazon、Google），转给非关联方后自动转为 Class A
  • Class T：仅有选举/罢免"Class T 董事"的权力，由长期利益信托（LTBT）持有，构成董事会多数席位来源
  • Class F：创始人 LLC 持有，拥有 50.1% 总投票权，但无经济权利
  • Class E：发给员工，仅就特定事项投票，无经济权利
"我们是一家特拉华州公益公司（PBC）……董事会必须平衡股东的经济利益、受我们行为实质影响者的最佳利益，以及公司章程中确定的特定公益目的：为人类长期利益负责任地开发和维护先进 AI。" — 招股书封面，关于 PBC 与 LTBT 的设计

这套结构等于把「使命优先」写进了法律文件：创始人拿投票权不拿钱，信托拿董事席位不拿股份，AI 安全目标优先于短期利润最大化。对二级市场投资者来说，这是买入前必须接受的"治理折价"。另有一个细节：公司向全资子公司捐赠了 8.468 亿股 Class N（占 6/30 全面摊薄后 5%），并设定"股价每涨 50% 再追加 2%"的机制；七位创始人各自承诺把 80% 的个人股权捐给慈善。

03业务：从"卖模型"到"卖工作成果"

招股书全文贯穿着一个叙事转向：Anthropic 不再把自己描述为模型 API 供应商，而是 "Virtual Collaborators"（虚拟协作者）——能自主跑几个小时到几周任务、能读文件、能操作应用、能完成多步工作流的"数字同事"。终端产品线包括 Claude Code（编码）、Claude Cowork（知识工作，2026 年 1 月研究预览，9 月与 Claude.ai 合并）、Claude Design。模型家族是四档：Mythos（含 Fable）OpusSonnetHaiku。

读法一：807 亿净亏损是个"假象"，但不能全当假象。

2026H1 净亏损 807.5 亿美元里，723.9 亿是估值上涨触发的可转债公允价值变动——公司越值钱，这笔账面亏损越大，且不消耗一分现金。真正反映经营的经营亏损是 6.93 亿，比去年同期的 21.35 亿大幅收窄，经营利润率从 -184% 收敛到 -4%。

同时也要看到：2025 年有一笔 15 亿美元的 Bartz 和解金（一次性、计入经营费用），以及 2026H1 有 87.57 亿的其他收支（计入其他收入/支出净额），这两块把 GAAP 口径弄得更花。

现金流的形态已经很明显：经营开始造血，但资本开支以 4 倍于经营现金流的速度抽出去，缺口靠融资填。这是一个典型的"卖得越好、越要借钱扩产"的重资产化转折——招股书称之为从"纯云采购"转向"混合模式"。

05算力：这份招股书里最重要的一张牌

"我们跨四大芯片家族（AWS Trainium、Google TPU、NVIDIA GPU 和 AMD GPU）原生训练与提供 Claude，并通过专有编排层按价格与性能优化工作负载……这减少了我们对任何单一供应商的依赖，并允许我们持续把工作负载路由到最优硬件。" — S-1「Compute Efficiency · Multi-Chip Compute Approach」
$10.8B
剩余履约义务（RPO，2026/6/30），约 75% 将在 12 个月内确认

三件事值得单独拎出来

  • "去单一依赖"是技术事实，不是公关话术。四家芯片原生支持，是多年工程投入的结果；招股书明确说这"难以在规模上被复制"。这解释了它为什么能在算力紧缺环境下保持交付。
  • Anthropic Direct：自己租芯片、自己布机房。从"只买云"转向"租芯片 + 自建/托管专属设施"，逻辑是把"数据中心容量"（交付周期长、占比小）与"加速器投资"（金额大、变化快）解耦，先锁机房、后买算力。招股书承认这会显著改变现金流形态，并在可预见未来持续产生大额净现金流出。
  • 20 年期的 take-or-pay 条款。风险章节明确披露：部分专属电力与数据中心安排初始期限 20 年、含年度涨价、照付不议、以及不受限的燃料成本传导——这是比 SaaS 公司重得多的资产负债表承诺。

与两大战略伙伴的绑定（招股书披露）

  • Google：2026 年票据购买协议（NPA）——按第三方算力协议里程碑与 TTM 收入目标触发提款，提款期至 2030/12/31；Google 持股上限 14.99%；同时授予 Google 最高 100 亿美元 Class N 的私募认购期权，行权价等于 IPO 发行价。
  • Amazon：可转债按持股上限转换为 Class N（上市前完成一部分，余额上市后可继续转）；上市后 Amazon 与 Google 各自持股均超过 5%，但都是无投票权的 Class N。
  • 安全垫：2026 年 9 月签的 A&R 循环授信额度 150 亿美元（2026/6/30 时提款为零），另有战略伙伴提供的票据购买与股权承诺额度。

⚠️ 一个容易被忽略的循环结构：这些既是算力供应商、又是股东、同时又提供信用支持——而它们自己也做竞争性模型。招股书在风险章节直接承认这类利益冲突可能影响算力获取、成本、工作负载优先级。

06风险清单：招股书自己划的重点

① 收入增长的可持续性存疑。公司自陈"过去曾难以准确预测收入，未来可能仍难"；并明确预期增速将随时间下降。
② 客户集中与渠道依赖。2025 年有单一客户贡献 12% 收入；通过云厂商 marketplace 产生的收入占比已从 2023 年的 11% 升至 2025 年的 47%、2026H1 的 48%；应收账款中 58% 来自 marketplace 渠道。
③ 违规使用带来的收入需剔除。公司估计 2026 前三季度约 5%~7% 的收入来自事后被判定违反使用政策的客户，且已在 2026 年 8–9 月加强检测执法。
④ 算力承诺的刚性。长期租约、照付不议、20 年期含涨价条款的电力与机房安排，技术路线一旦变化可能变成"不合用但必须付"的负担。
⑤ 供应链与出口管制。先进芯片来自有限供应商与地区，面临供应紧张与不断演变的出口管制。
⑥ "Closing the loop" 的反身风险。模型参与设计和训练下一代模型，任何系统性缺陷可能在代际间被放大且难以察觉。
⑦ 治理折价。PBC + LTBT + 创始人 50.1% 投票权的结构，使外部股东对重大决策影响力有限，公司同时是 Nasdaq 定义的"受控公司"。

07募集资金用途

招股书列出的用途是典型的成长期科技公司表述（具体金额留白）： 算力与基础设施扩建、推动 Claude 采用（直销团队、Applied AI、云分销、品牌与国际化）、进入新市场（医疗与生命科学、机器人、物理世界工作）、战略性交易与伙伴关系，以及营运资金与一般企业用途。另需预留资金用于 RSU 结算的预扣税与代缴义务。

08三条判断（我的读法）

1. 这是一份"用非现金亏损换增长叙事"的招股书，但底子比叙事硬。807 亿净亏损的注意力噪音必须剥离，剩下的 6.93 亿经营亏损 + 16% 的经营利润率改善 + 现金流由负转正，是能站住的经营证据。

2. 真正的估值变量不在损益表，在承诺表。未来十年算力采购与租约的规模（招股书金额留白，但明确"2030 年前集中体现、2031–2045 分摊"）将与收入增速赛跑。如果单位经济（收入/算力美元）持续改善，这个模式成立；一旦模型效率曲线放缓，20 年期照付不议就会变成负资产。

3. 治理结构值得折价，不应折掉全部。PBC + 信托多数董事 + 创始人绝对投票权，意味着投资人买的是"管理层的使命执行力"，而不是"可被股东施压调整的战略"。接受这条，才谈得上接受这个估值。
